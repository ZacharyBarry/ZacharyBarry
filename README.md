**[Advanced Keyboard Automation](https://github.com/ZacharyBarry/autoclicker-macro)**
A multi-threaded Python automation tool with a Tkinter GUI. Records, edits, and executes complex macros using conditional, on-screen visual logic, leveraging `pynput` and `mss` for seamless background execution.
